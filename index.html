Nova tarefa
Conectar ao Airtable
Configure em 5 minutos:
1. Acesse airtable.com → crie conta gratuita
2. Crie uma Base chamada Tarefas Campo
3. Renomeie a tabela para Tarefas e adicione as colunas:
   titulo · quem · prio · prazo · status · emp · desc · criada
   (todas Texto, exceto prazo = Data e desc = Texto longo)
4. Vá em airtable.com/create/tokens → crie um token
   Escopos: data.records:read e data.records:write
5. Copie o ID da Base da URL: airtable.com/appXXXXXX/...
